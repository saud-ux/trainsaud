# برنامج اليو‑يو — Yo‑Yo IR1 Trainer

موقع صفحة واحدة (HTML / CSS / JavaScript، بدون أي أدوات بناء) يعرض برنامج تدريب **٨ أسابيع** لاجتياز اختبار
`Yo-Yo Intermittent Recovery Test — Level 1`
على شكل **تمارين مهيكلة** جاهزة للإدخال في
`Garmin Connect`
وتُقاد بالاهتزاز على ساعة
`Vivoactive 5`.

## التشغيل
افتح `index.html` في المتصفّح مباشرة — الملف مستقلّ بذاته. كتطبيق `PWA` يُقدَّم عبر خادم `HTTPS` (مثل `Netlify`) ليُثبَّت ويعمل دون إنترنت.

## المزايا
- **٣٢ تمرينًا** موزّعة على ٨ أسابيع (تأسيس ← بناء ← استشفاء ← تخفيف).
- **نطاقات نبض تفاعلية** بطريقة `Karvonen`؛ عدّل العمر/نبض الراحة/النبض الأقصى المُقاس فتتحدّث كل أهداف التمارين تلقائيًا.
- **موعد اختبار قابل للتعديل** يحرّك العدّاد التنازلي ويوم الاختبار.
- **مشغّل صافرات `YYIR1` مدمج** (`Web Audio`): نغمات البروتوكول بالمستويات والسرعات القياسية، بلا تطبيق منفصل.
- **تطبيق `PWA`** قابل للتثبيت يعمل دون إنترنت (`service worker` + خطوط مخزّنة).
- بطاقة لكل تمرين بصيغة خطوات `Garmin` الدقيقة، مع زر **نسخ الخطوات** وعلامة **إنجاز** تُحفظ في المتصفّح.
- دليل الإدخال والمزامنة، إعدادات الساعة، وسكربت `Node.js` اختياري لتوليد ملفات `FIT`.
- سمة فاتحة/داكنة، وتصميم يمين‑لليسار.

## الملفّات
`index.html` (الموقع) · `manifest.json` + `sw.js` (الـ PWA) · `icons/` (أيقونات مولّدة) · `README.md`.
